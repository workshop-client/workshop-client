# Attribution

Workshop Client uses the MIT-licensed `phoenix-hook` and `phoenix-sigs` crates from [Sunbird](https://github.com/sunbird-tools/sunbird), pinned to commit `8559cbeeea56a430605217b065a7f020ff72fe4b` in Cargo.toml. Sunbird's native ABI research informed the Phoenix adapters.

Clear URLs uses tracking rules from Sunbird's Clear URLs plugin by amaanq. Global Badges is based on the behavior of Sunbird's Global Badges plugin by iFlex0x and wolfieeeeeeee. Their implementations, protocol documentation, and source links are recorded in each plugin's README.

[Astral](https://github.com/astral-app/astral) was studied as a reference for a native plugin client.

Other Rust dependencies retain their respective licenses. Discord binaries, artwork, user data, and credentials are not distributed in this repository. Community badge artwork comes from its respective providers.
